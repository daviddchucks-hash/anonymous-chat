Passerby

Talk to a stranger. When you leave, the chat is gone.

Passerby pairs you with a random person for a one-off text conversation. There are no accounts, no profiles and no saved history. You get a temporary name like Stranger-48291 that lasts for a single conversation.

What stays private

No sign-up
No email, phone number, password, real name or photo. Nothing ties you to a permanent profile.
No saved chats
Messages exist only in the server's memory while the conversation is active, and are deleted when it ends. Message contents are never logged.
A name that expires
The other person sees a random name, and only for this one conversation.
Hidden from the stranger
Your IP address and technical identifiers are never shown to the person you talk to.

What is not hidden

Anonymous to other users is not the same as untraceable.

The server and the hosting network can still process connection details such as your IP address, and your internet provider can see that you connected. The stranger can also copy or screenshot what you write. Don't share anything personal.

House rules

  • For adults only (18+).
  • Be respectful. Use Report or Block if someone is not.
  • Spam, links and abusive language are filtered, and repeat offenders are temporarily blocked.

What do you want to talk about?

We'll look for someone who picked the same topic. If nobody is around, you can choose to talk to anyone instead.
